### About Zunix

**Zunix** is an independent Czech technology brand focused on building modern web experiences, infrastructure and software.

From websites and managed hosting to custom applications, the goal is simple — create technology that is **clean, reliable and easy to use**.

### What we build

🌐 **Web**  
Modern websites, custom web solutions and long-term technical care.

🖥️ **Infrastructure**  
Managed hosting and infrastructure built around our own systems.

📦 **Software**  
Tools and applications designed to make everyday work simpler.
